# ZK nextgen energy — portfolio website

Bilingual corporate website for ZK nextgen energy s.r.o.

## Languages
- `/` or `/index.html` = Czech
- `/en.html` or `/en` = English

## Current positioning
The website presents the company as a multi-project development platform rather than a single Poland biomethane project.

Current public portfolio themes:
- Biomethane / renewable gas in Europe
- Renewable and landfill gas in Senegal
- Pyrolysis / circular infrastructure in Africa
- Pyrolysis / circular infrastructure in Asia

Sensitive project details such as exact locations, counterparties and detailed financial models are intentionally not published.

## Render deployment
1. Upload and overwrite all files from this package in the GitHub repository connected to Render.
2. Do not upload `node_modules`.
3. Make sure no obsolete `Server.js` with a capital `S` remains in the repository.
4. Render settings:
   - Build Command: `npm install`
   - Start Command: `npm start`
5. After deployment use `Ctrl + F5` once if the browser still shows cached assets.
